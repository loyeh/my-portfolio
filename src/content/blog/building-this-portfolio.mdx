Most portfolio sites curate away the mess: a handful of polished projects,
a tidy bio, a stock-photo headshot. That felt dishonest for where I
actually am — most of my public work is small, timeboxed practice, not
finished products.

So instead of hiding that, this site leans into it:

- **Projects** are pulled live from the GitHub API, not hand-picked and
  frozen in time.
- A small number of repos get a full case-study writeup; the rest link
  straight out to GitHub.
- The **experience timeline** reads like a changelog, in chronological
  order, not reordered for effect.

## Stack

Built with Next.js (App Router), TypeScript, and Tailwind CSS v4. Blog
posts are MDX files rendered server-side with `next-mdx-remote`, no extra
content pipeline. Dark mode via `next-themes`, motion via `motion`.
